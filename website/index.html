Features

Everything on screen is live, drawn, and verified.

No embedded web view, no shelling out to parse porcelain, no repainting the world per row. One window, rendered by the GPU, fed by a real Git object database.

⌥

A commit graph painted properly

Every visible lane, curve, and node is painted in a single GPU canvas per frame — cubic Bézier merges with vertical tangents, per-line colors that survive lane changes, and a halo on HEAD. No element-per-segment DOM soup.

∞

Kernel-scale by default

History streams in progressive 256/512-row batches from a persistent cursor that never restarts. The Linux kernel's 1,464,430 commits scroll like a small repository.

◉

Live repository watching

Create a branch or tag in your terminal and it appears in the sidebar within ~150 ms — while your scope and selected commit stay exactly where you left them.

⎇

Worktrees are first-class

Linked worktrees appear beside branches and remotes with their checked-out branch, locked state, and health — including checkouts that have gone missing.

⇲

Resizable everything

Drag the sidebar, the graph column, and the details panel. Wide merge histories can open the graph to dozens of visible lanes.

Δ

Changed files at a glance

Selecting a commit shows its file changes with Git's own status letters — debounced, so holding an arrow key never decodes commits you fly past.

⌨

Keyboard-first history

Arrows, Page Up/Down, Home and End drive the list through declared, rebindable actions. Selection follows the commit, not the row number.

✓

Verified against real repositories

A stress harness validates the exact data the painter consumes — cross-row line continuity, color for color — across 18 real repositories including linux, git, and WordPress.

λ

Branch scoping in one click

Click a branch to scope history to it; click again to widen back to all refs. External updates re-resolve the tip so the walk never goes stale.

Under the hood

A hybrid engine with no shortcuts.

gix for every read

Direct object-database access: incremental traversal, reusable caches, and data structures independent of subprocess text formats.

Your real Git for mutations

Fetch and branch operations run the installed git, inheriting your credential helpers, SSH setup, and hooks untouched.

GPUI, the engine behind Zed

Metal-rendered UI with a virtualized list — one element per visible row, one canvas for the whole graph, every frame.

Rust with the guardrails on

unsafe_code = "forbid" across the workspace, pedantic Clippy as an error, and a UI that never blocks on the filesystem.
